# Independent Docker integration

`pnpm test:docker` starts a throwaway, project-scoped Snipe-IT v8.3.1 and MariaDB 11.4.7 stack on port 18080. It does not use the Python repository's containers, network, token, files, or default port.

The runner removes only the `snipeit-typescript-integration` Compose project's old volumes, creates an empty ignored `api-token.txt`, starts the database/seeder/application, and waits for **both**:

1. a non-empty token generated by `snipeit:make-api-key`; and
2. a successful authenticated `GET /api/v1/users/me` using that token.

It then runs `tests/integration/docker.mjs` against built package output and always tears down its own containers and volumes. Failures include Compose logs. Docker must already be running; the script never starts a host daemon or VM.

Set `SNIPEIT_DOCKER_PORT` if port 18080 is occupied; the same value configures both the published port and Snipe-IT's `APP_URL`.
